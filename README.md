# 서연이의 8번째 생일 선물 사이트 🎂

브라우저에서 `index.html` 만 열면 동작하는 정적 사이트입니다. (서버, 빌드 필요 없음)

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 두 페이지(하트 / 편지)의 뼈대 |
| `style.css` | 디자인, 봉투·편지지·하트 애니메이션 |
| `script.js` | 하트 배치, 글자 날아오기, 편지 손글씨, 노래, 페이지 전환 |
| `music/song.mp3` | Suno로 만든 노래 |
| `photos/1.jpg`, `2.jpg` … | (직접 넣기) 하트 장면에 떠다니는 사진 |

## 흐름

0. **시작 화면**: 두근거리는 하트 버튼이 먼저 나옵니다. 하트를 누르는 순간 노래가 시작되고 1페이지로 들어갑니다.
   (브라우저는 사용자가 한 번 누르기 전에는 소리를 못 내게 막기 때문에, 이 터치가 노래를 켜 주는 역할을 합니다.)
1. **1페이지 – 하트**: 각 나라 말 "사랑해"가 1개, 2개, 3개… 점점 많이 날아와 하트가 됩니다.
   가운데는 분홍, 바깥으로 갈수록 빨강입니다. 완성되면 아래에 `서연아 8번째 생일 축하해` 가 뜹니다.
2. 하트 완성 **10초 뒤** 자동으로 2페이지로 넘어갑니다.
3. **2페이지 – 편지**: 봉투가 열리고 편지지가 나온 뒤, 펜으로 쓰듯 한 글자씩 편지가 써집니다.
4. 다 쓰고 나면 그대로 멈춰 있고 반복하지 않습니다. 새로고침하면 처음부터 다시 시작합니다.
5. 아래 버튼으로 두 페이지를 언제든 오갈 수 있습니다. (이미 본 장면은 다시 재생하지 않습니다)

## 사진 넣기

`photos/` 폴더에 `1.jpg`, `2.jpg`, `3.jpg` … 순서대로 넣으면 하트 장면에서 폴라로이드처럼 떠다닙니다.
코드를 고칠 필요는 없고, 번호가 끊기는 곳까지 자동으로 읽습니다. 자세한 건 `photos/README.md` 참고.

## 노래 넣기

`music/song.mp3` 로 저장하면 시작 화면의 하트를 누르는 순간부터 반복 재생됩니다. 자세한 건 `music/README.md` 참고.
파일이 없으면 노래 없이 그대로 진행됩니다.

## 바꿀 수 있는 값 (`script.js` 맨 위 `CONFIG`)

- `songUrl` 노래 파일 경로 (`''` 로 두면 노래 없음)
- `volume` 처음 음량 (0 ~ 1). 사이트 안에서도 오른쪽 위 스피커 버튼을 누르면 막대로 조절하거나 끌 수 있습니다.
- `secondsBeforeLetter` 하트 완성 후 편지로 넘어가기까지의 초
- `heartWordCount` 하트를 이루는 단어 개수
- `batchIntervalMs` 단어 묶음이 날아오는 간격
- `typingMs` 편지 글씨 속도

편지 내용은 `script.js` 의 `LETTER_LINES` 에서 고칠 수 있습니다.
