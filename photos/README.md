# 사진 넣는 방법

1. 하트 장면에 띄우고 싶은 사진을 이 폴더(`photos/`)에 넣습니다.
2. 파일 이름을 `1.jpg`, `2.jpg`, `3.jpg` … 처럼 1번부터 순서대로 붙입니다. (png 도 됩니다)
3. 번호가 끊기는 곳까지만 읽으니 중간을 비우지 마세요. 최대 30장.

사진은 폴라로이드처럼 흰 테두리를 두르고 정사각형으로 잘려서 하트 뒤를 천천히 떠다닙니다.
휴대폰에서 빨리 뜨도록 한 장에 500KB 이하, 가로세로 1000px 정도면 충분합니다.
사진이 한 장도 없으면 이 기능은 그냥 꺼진 채로 동작합니다.
